# Campus Bites

A collaborative HTML and CSS project for a fictional university cafeteria.

---

## 📌 Project Overview
**Campus Bites** is a modern and accessible campus cafeteria website designed to simplify cafeteria menu browsing, meal planning, meal deals, order tracking, and student feedback.

## 📄 Pages Structure
- **Home** (`src/index.html`): Main landing page highlighting cafeteria specials and announcements.
- **Contact** (`src/contact.html`): Cafeteria location, operational hours, and contact details.
- **Menu** (`src/menu.html`): Detailed catalog of food and beverage offerings.
- **How to Order** (`src/order.html`): Instructions and step-by-step cafeteria ordering form/process.
- **Daily Deals** (`src/deals.html`): Special discounted combos and student meal packages.
- **Feedback** (`src/feedback.html`): Customer reviews, ratings, and suggestion submissions.
